# هەیکەلێ ڕۆبۆتی بۆ چاپکرنا 3D

| فایل | پارچە | ژمارە |
|---|---|---|
| `head_front.stl` | پێشیا سەری، پەنجەرا شاشا OLED و کونا مایکی تێدا نە | 1 |
| `head_back.stl` | پشتا سەری | 1 |
| `body_front.stl` | پێشیا لەشی، کونێن بلندگۆیێ تێدا نە | 1 |
| `body_back.stl` | پشتا لەشی | 1 |
| `arm_x2.stl` | دەست (بۆ سێرڤۆ SG90) | 2 |
| `base.stl` | بنک، کونا USB و سویچی تێدا نە | 1 |
| `base_lid.stl` | سەرێ بنکی یێ خوارێ | 1 |
| `neck_ring.stl` | ستۆ، سەری ب لەشی ڤە گرێددەت | 1 |

- پێڤەر: سەر 80×60×66 mm، لەش 76×56×80 mm، بنک Ø110×26 mm.
- چاپکرن: PLA، دیوار 2 mm، infill 15%. هەمی پارچە ب لایێ ڤەکری ل سەر تەختێ هاتینە دانان؛ پێدڤی ب support نینە (تنێ بۆ کونا USB یا بنکی دبیت).
- هەردو نیڤێن سەری و لەشی ب چەسپێ گەرم یان چەسپێ CA ب ئێک ڤە بنووسینە، بەلێ پێشیێ پارچەیان تێدا دانە.
- ئەگەر پێڤەرێن پارچێن تە جودا بن، ژمارێن ل سەرێ `make_robot_stl.py` بگوهۆڕە و دووبارە ب کار بینە:

```
pip install manifold3d numpy
python make_robot_stl.py
```
