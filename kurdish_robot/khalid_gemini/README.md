# رۆبۆتێ خالد 🤖 — Gemini + کوردیا بادینی

**BOOT** بگرە و باخڤە، پاشی بەردە. خالد گوهداریێ دکەت، ب Gemini دهزرت، و ب بادینی بەرسڤێ ددەت.
ئەو کۆمیدیە، یاریان دکەت (مەتەڵ، هەژمارێ بزانە، کێ ئەز؟...) و هندەک جاران ب یاری تورە دبیت 😠😄

## چاڤێن خالدی
| دلخۆش | کۆمیدی (چاڤ قوچاندن) | تورە | خەمگین | حەز | عەجێبمای | گوهداری | دهزرت | نڤستی |
|---|---|---|---|---|---|---|---|---|
| ^ ^ | ● — | ◣ ◢ | ◢ ◣ | ♥ ♥ | ◉ ◉ | ◉ ◉ | ■ ■ ↑ | — — z |

باتری ل سەری لایێ راستێ دیار دبیت؛ ⚡ = شەحن دبیت، **LOW** = کێمە.

## دانان
1. `secrets_example.h` کۆپی بکە بۆ `secrets.h` و WiFi و کلیلا Gemini تێدا بنڤیسە.
2. Arduino IDE: بۆرد **ESP32 Dev Module**، کتێبخانە **U8g2**.
3. Upload، پاشی Serial Monitor ل **115200**.

## گرێدان
| پارچە | پین |
|---|---|
| شاشە | VCC 3V3، GND، SCL 22، SDA 21 |
| مایک INMP441 | VDD 3V3، GND، L/R GND، WS 33، SCK 32، SD 35 |
| ئەمپ MAX98357A | VIN 5V، GND، LRC 25، BCLK 26، DIN 27 |
| باتری (نوو) | باتری+ ← 100k ← GPIO34 ← 100k ← GND |

## ئەگەر کار نەکر
| ل سەر شاشێ | چ بکەی |
|---|---|
| `no WiFi` | ناڤ و پاسوۆردا WiFi ل `secrets.h` (پیتێن مەزن و بچویک گرنگن) |
| `mic silent` | تێلێن مایکی، یان `MIC_RIGHT = true` |
| `text error 400/403/404` | کلیل یان ناڤێ مۆدێلی (`TEXT_MODEL`) |
| `text error 401` | کلیلێن `AQ.` هندەک جاران کار ناکەن، کلیلەکا نوو چێکە |
| `voice error ...` | `TTS_MODEL` بگوهۆڕە، یان دەنگ بۆ کوردی نینە |
| `no connection` | `REC_SECONDS` بکە 3 (بیرا ESP32 کێمە) |
