# دەنگێ بادینی بۆ رۆبۆتێ زیرەک 🎙️

[`READ_ME_ALOUD.md`](READ_ME_ALOUD.md) ١٠٠٠ رستێن بادینی تێدا هەنە کو تو ب دەنگێ خۆ تۆمار بکەی.
پشتی تۆمارکرنێ، دەنگێ رۆبۆتی ب **Piper** پەروەردە دکەین دا ب دەنگێ تە باخڤیت.

## چاوا تۆمار بکەی (رێکا هاسان)

ب تنێ **٢٠ فایلان** تۆمار بکە، هەر ئێک ٥٠ رستە. نەچاری ١٠٠٠ فایلان ناڤ بکەی.

1. ئەپا تۆمارکرنێ ل موبایلێ ڤەکە و ⏺ بکە.
2. **ستۆدیۆیا زیرەک** ڤەکە (`studio.html`، یان لینکا Claude) و پشکەکێ هەلبژێرە.
3. رستێ بخوینە و **دویڤدا** بکە. پەیج ٢ چرکان بێدەنگیێ ددەتە تە، پاشی رستا دویڤدا نیشا تە ددەت.
4. ئەگەر خەلەت خواند، **خەلەت بوو، دووبارە** بکە و هەمان رستێ دووبارە بخوینە.
5. ل دوماهیێ ⏹ بکە و ناڤێ فایلی بکە ئەوێ پەیج نیشا تە ددەت، بۆ نموونە `b03` یان `b03_r112_131`.
6. فایلی بکە ناڤ فۆڵدەرێ **Zirek** ل Google Drive.
7. ل Colab پشکا **✂️** ▶️ بکە. `split_blocks.py` هەر فایلەکێ دکەتە ٥٠ فایلان: `badini_0101.wav`...

جهەکێ بێ دەنگ هەلبژێرە، و موبایلی ل سەر مێزێ ٢٠–٣٠ سانتیمەتران دوور دانە ([وێنێ رێنماییێ](recording_guide.png)).

## ئەگەر رستەک خەلەت بیت ⚠️
رستە ب دەستێ Claude AI هاتینە نڤیسین. هندەک پەیڤ دبیت وەکی لەهجا تە نەبن.
- رستێ **وەکی تو ب بادینیا راستەقینە دبێژی** بخوینە.
- پاشی نڤیسینا وێ ل `src/*.txt` راست بکە (ب پیتێن لاتینی) و `python3 build_dataset.py` بکە.
- **گرنگە** کو نڤیسین و دەنگ وەکی ئێک بن، دەنگ ب تنێ ب ڤی رەنگی دێ باش بیت.

## فایل

| فایل | چیە |
|------|-----|
| `src/*.txt` | رستە ب پیتێن لاتینی (Kurmancî). ئەڤان بگوهۆڕە. |
| `build_dataset.py` | ژمارە ددەتە رستان و دکەتە پیتێن عەرەبی |
| `READ_ME_ALOUD.md` | لیستا خواندنێ |
| `studio.html` | ستۆدیۆیا خواندنێ (ژ `studio_template.html` دروست دبیت) |
| `split_blocks.py` | تۆمارێن درێژ دکەتە ئێک فایل بۆ هەر رستەکێ |
| `sentences.tsv` | لیستا هەمیان: هەژمار، لاتینی، عەرەبی |
| `metadata.csv` | بۆ پەروەردەکرنا Piper (LJSpeech format) |
