# دەنگێ بادینی بۆ رۆبۆتێ زیرەک 🎙️

[`READ_ME_ALOUD.md`](READ_ME_ALOUD.md) ١٠٠٠ رستێن بادینی تێدا هەنە کو تو ب دەنگێ خۆ تۆمار بکەی.
پشتی تۆمارکرنێ، دەنگێ رۆبۆتی ب **Piper** پەروەردە دکەین دا ب دەنگێ تە باخڤیت.

## چاوا تۆمار بکەی

1. **جهەکێ بێ دەنگ** هەلبژێرە: ژوورەکا بچویک یا دۆشەک و پەردە تێدا هەین باشترە.
2. موبایلی **٢٠–٣٠ سانتیمەتران** ژ دەڤێ خۆ دوور بگرە، و هەر جار ل هەمان جهی.
3. **ب ئاسایی** باخڤە، وەکی تو دگەل هەڤالەکی دئاخڤی. نە ب لەز و نە ب هێدی.
4. پێش و پشتی هەر رستەکێ **نیڤ چرکە** بێدەنگ بە.
5. هەر رستەکێ **فایلەکێ جودا** بکە و ناڤێ وێ بکە هەژمارا رستێ: `badini_0001.wav`، `badini_0002.wav` ...
6. ئەگەر خەلەت خواند، دووبارە تۆمار بکە.
7. رۆژانە **١٠٠–٢٠٠ رستان** تۆمار بکە دا دەنگێ تە نەوەستیت. هەمی تۆمار دڤێت **ب هەمان دەنگی** بن.

**ئەپ:** ل ئەندرۆیدێ "ASR Voice Recorder" یان ئەپەکێ دی بکار بینە کو دشێت WAV تۆمار بکەت (44100 Hz، mono).

## ئەگەر رستەک خەلەت بیت ⚠️
رستە ب دەستێ Claude AI هاتینە نڤیسین. هندەک پەیڤ دبیت وەکی لەهجا تە نەبن.
- رستێ **وەکی تو ب بادینیا راستەقینە دبێژی** بخوینە.
- پاشی نڤیسینا وێ ل `src/*.txt` راست بکە (ب پیتێن لاتینی) و `python3 build_dataset.py` بکە.
- **گرنگە** کو نڤیسین و دەنگ وەکی ئێک بن، دەنگ ب تنێ ب ڤی رەنگی دێ باش بیت.

## فایل

| فایل | چیە |
|------|-----|
| `src/*.txt` | رستە ب پیتێن لاتینی (Kurmancî). ئەڤان بگوهۆڕە. |
| `build_dataset.py` | ژمارە ددەتە رستان و دکەتە پیتێن عەرەبی |
| `READ_ME_ALOUD.md` | لیستا خواندنێ |
| `sentences.tsv` | لیستا هەمیان: هەژمار، لاتینی، عەرەبی |
| `metadata.csv` | بۆ پەروەردەکرنا Piper (LJSpeech format) |
