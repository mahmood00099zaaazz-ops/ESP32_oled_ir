چاوا کۆدی ژ لاپتۆپێ بۆ ESP32 بفرێکی

لاپتۆپ ب کێبلا USB-C ڤە ب بۆردێ ڤە گرێدە، د Arduino IDE دا بۆرد و پۆرتی هەلبژێرە، پاشی Upload بکە.

ئامادەکرنا لاپتۆپێ، ڕێک ب ڕێک

ئەڤ کارە بەس جارەکێ ل سەر لاپتۆپێ دکەی. خانێن ب چوارچۆڤێ پرتەقالی، ئەو جهن یێن تو ل سەر دکەی یان تێدا دنڤیسی.

  1. Arduino IDE دابەزینە و install بکە

    ڤی ماڵپەڕی ڤەکە، Windows هەلبژێرە، پاشی Next ← Next ← Install.

    arduino.cc/en/software
    Arduino IDE 2
    Windows Win 10 and newer, 64 bits
    Linux · macOS
  2. لینکێ ESP32 دانە د Preferences دا

    Arduino IDE ڤەکە: File ← Preferences. لینکی کۆپی بکە و د خانا ژێرێ دا دانە، پاشی OK.

    Preferences
    Sketchbook location:C:\Users\Dell\Documents\Arduino
    Additional boards manager URLs:https://espressif.github.io/arduino-esp32/package_esp32_index.json
    OK
  3. بۆردا ESP32 install بکە

    Tools ← Board ← Boards Manager، بنڤیسە esp32، و INSTALL ل سەر یێ Espressif بکە. چەند خولەکان دڤێت.

    Boards Manager
    esp32
    esp32 by Espressif Systems
    Boards included: ESP32 Dev Module, ESP32-S3…
    INSTALL
  4. کتێبخانا U8g2 دانە (بۆ OLED)

    Sketch ← Include Library ← Manage Libraries، بنڤیسە U8g2 و INSTALL بکە.

    Library Manager
    U8g2
    U8g2 by oliver
    INSTALL
  5. ESP32 گرێدە و پۆرتی بپشکنە

    ب کێبلا USB-C یا data گرێدە. د Windows دا Device Manager ڤەکە (کلیکا ڕاست ل سەر Start). ل ژێر Ports دڤێت پۆرتەک دیار ببیت.

    Device Manager
    ▾ Ports (COM & LPT)
    USB-SERIAL CH340 (COM5)

    ئەگەر Ports نەبوو، یان ⚠ ل بەر دیار بوو: driverێ CH340 یان CP2102 دابەزینە، یان کێبلەکا دی تاقی بکە.

  6. بۆرد و پۆرتی هەلبژێرە

    ژ مێنیوا Tools:

    Tools
    Manage Libraries…
    Board: "ESP32 Dev Module"
    Port: "COM5"
    Upload Speed: "921600"
  7. Upload بکە

    فایلا OLED_IR_CODE.ino ڤەکە: File ← Open. پاشی دووگمەیا Upload بکە.

    OLED_IR_CODE | Arduino IDE
    ✓→ UploadESP32 Dev Module · COM5
    Connecting....... Writing at 0x00010000... (100 %) Leaving... Hard resetting via RTS pin...

    ئەگەر ل سەر Connecting....... ڕاوەستیا: دووگمەیا BOOT ل سەر بۆردێ ڤە بگرە هەتا % دیار دبیت.

ئەگەر کار نەکر

  • Connecting....... ڕاوەستیا: دووگمەیا BOOT ڤە بگرە هەتا % دەست پێ دکەت.
  • پۆرت ل Tools دیار نینە: کێبلەکا دی تاقی بکە، یان driver دابەزینە.
  • پشتی upload شاشە ڕەشە: دووگمەیا EN پاڵ بدە و تەلێن OLED کۆنترۆل بکە.
