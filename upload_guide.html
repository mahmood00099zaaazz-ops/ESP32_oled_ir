چاوا کۆدی ژ لاپتۆپی بۆ ESP32 فرێکەی

لاپتۆپ ← کێبلێ USB-C یێ داتا ← ESP32. ب Arduino IDE.

  1. ١

    Arduino IDE دابەزینە

    ل سەر لاپتۆپی بچە: arduino.cc/en/software و Windows دابەزینە.

  2. ٢

    ESP32 زێدە بکە

    File → Preferences ← ڤێ لینکێ ل Additional boards manager URLs دانە:

    https://espressif.github.io/arduino-esp32/package_esp32_index.json

    Tools → Board → Boards Manager ← esp32 ← esp32 by Espressif ← Install

  3. ٣

    کتێبخانا U8g2 دامەزرینە

    Sketch → Include Library → Manage Libraries ← U8g2 ← Install

  4. ٤

    بۆرد و پۆرت هەلبژێرە

    Tools → Board → ESP32 Dev Module و Tools → Port → COM3

    ئەگەر COM دیار نەبوو: کێبلەکێ دی تاقی بکە، یان درایڤەرێ CP2102 / CH340 دامەزرینە.
